Inventory Demand Prediction and Stock Optimization Intelligence System

Project Overview

This project is a Business Intelligence system that analyzes retail inventory and sales data to understand demand patterns, identify inventory risks, and support better stock management decisions.

Objectives

- Analyze retail sales and inventory data
- Identify important sales and inventory trends
- Predict product demand
- Identify products at risk of overstocking or stock shortages
- Provide useful business recommendations
- Build an interactive dashboard for decision-making

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- GitHub

Dataset

The project uses the Retail Store Inventory Forecasting dataset.
